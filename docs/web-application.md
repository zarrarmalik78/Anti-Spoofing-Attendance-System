# University Web Application

The Edge AI Attendance System includes a modern web-based dashboard for managing the university, tracking attendance, and monitoring the edge AI cameras in real time.

## Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **Backend / BaaS**: Firebase (Authentication & Cloud Firestore)

## Architecture & RBAC
The application is strictly governed by Role-Based Access Control (RBAC). 

1. **Authentication**: Users sign in via Firebase Email/Password (`Login.tsx`).
2. **Context**: `AuthContext.tsx` listens to the auth state, then queries the `users` Firestore collection to retrieve the user's explicit role (`student`, `teacher`, `hod`, `dean`, `vc`, `admin`) and their `scope` (e.g., which specific `departmentId` they control).
3. **Routing**: `ProtectedRoute.tsx` wraps all dashboards. If a user tries to access a URL they shouldn't (e.g. a Student trying to reach `/dashboard/admin`), they are immediately blocked.
4. **Navigation**: The `Sidebar.tsx` dynamically renders the correct links based on the user's role.

## Dashboards
- **Student Dashboard**: Shows personal attendance percentages, missed classes, and recent check-ins.
- **Teacher Dashboard**: Shows assigned classes, student counts, and aggregate attendance stats.
- **Admin/VC/Dean/HOD Dashboards**: Renders hierarchical statistics depending on the scope of the user. (Currently aggregated in `GenericAdminDashboard.tsx`).
- **Live Monitoring**: Listens to the `recognition_events` Firestore collection in real-time. When the Edge AI Desktop app identifies a face or a spoof attempt, it appears instantly on this page without refreshing!

## How to Run
1. Navigate to the `web/` directory.
2. Ensure you have installed dependencies:
   ```bash
   npm install
   ```
3. Copy the `.env` file from the project root and add the `VITE_` prefix to your Firebase keys:
   ```env
   VITE_FIREBASE_API_KEY=your-api-key
   VITE_FIREBASE_AUTH_DOMAIN=your-auth-domain
   ...
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:5173` in your browser.
6. Login using the test accounts generated by `src/scripts/create_user.py`.
